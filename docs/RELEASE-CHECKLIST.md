# 发布检查

- [ ] 仅从应用源码白名单整理发布目录，保留原用户安装目录不动。
- [ ] 自动识别当前用户的 Codex 目录，支持 CODEX_HOME。
- [ ] 配置和缓存存储在 LOCALAPPDATA/codex-tokenuse，与程序文件分离。
- [ ] 打包 Python/Tk 和固定版本 ccusage Windows x64 原生程序。
- [ ] 不打包桌宠素材、登录凭据、真实日志、用户截图或用量缓存。
- [ ] 单元测试、无 Node 环境自检、全新路径解压运行检查通过。
- [ ] 检查源码、压缩包文件清单及第三方许可证。
- [ ] 提供中文 README、项目介绍、下载包及 SHA-256 校验值。
- [ ] 创建公开 GitHub 仓库并发布经过验证的版本。
